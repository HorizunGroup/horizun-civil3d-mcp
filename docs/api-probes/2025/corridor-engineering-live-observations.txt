Corrected bounded option handling:
- UseSameSideTarget is read/set only for Offset in 2025+; absent in the measured
  2024 DLL, represented as null + unsupported_year_api.
- TargetToOption is read for Offset/Elevation only when >=2 targets are assigned.
  Other bridge-unsupported families report null + unsupported_target_type.
- Native InvalidOperationException on either applicable getter becomes null with
  native_getter_unavailable and the native message; no invented default.
- Offset setters accept Nearest/Farthest; Flattest/Steepest are refused before write.
  Elevation accepts all four native option values according to the API exception
  specification, which prohibits Flattest/Steepest specifically for Offset/OffsetPipe.
