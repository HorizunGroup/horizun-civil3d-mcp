# AGENTS.md

Any AI agent (Claude, Codex, Copilot, etc.) working in this repository must start by reading:

1. `docs/handoff/00_START_HERE.md`: purpose, the owner's instructions, every path, the contract.
2. `docs/handoff/STATUS.md`: the current state and **QUÉ SIGUE**, the next block of work.
3. `docs/handoff/WORKFLOW.md`: the mandatory work cycle. Always end by reporting what comes next.
4. `CLAUDE.md`: the engineering rules. They apply to every agent, not only Claude.

Report to the owner in Spanish, briefly.
